# Batoi Systems

Proyecto de Sistemas Operativos en Red del curso 2026-2027.

## Objetivos

- Diseñar una red informática.
- Configurar servidores Linux.
- Aprender a administrar sistemas en red.

## Tecnologías utilizadas

- Linux
- Ubuntu Server
- VirtualBox
- Git y GitHub

|--------|--------------|

## Instalación

Para actualizar los paquetes del sistema podemos usar el comando `sudo apt update`.

También podemos ejecutar los siguientes comandos:

```bash
sudo apt update
sudo apt upgrade
```
